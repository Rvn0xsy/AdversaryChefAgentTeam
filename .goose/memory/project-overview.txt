# AdversaryChefAgentTeam 项目概览

红队多功能 Agent 项目，基于 Multica + Codex 的协作式渗透测试平台。

## 核心架构
- **Multica 服务端**（自部署）：Postgres + Backend + Frontend，负责任务编排、Issue 管理、Agent 定义、Skills 存储
- **Daemon + Codex CLI**：Runtime 执行层，通过 cc-switch 模型路由至 DeepSeek V4 Pro
- **Kali MCP 容器**：暴露 Kali 工具链（nmap、metasploit、sqlmap、gobuster、hydra 等），异步 job 模式（exec → get_job → kill_job）
- **Asset MCP 容器**：资产/线索/凭据/工作日志 CRUD，SQLite 持久化

## MCP Server 技术栈
- Go 1.26.4 + modelcontextprotocol/go-sdk v1.6.1
- HTTP/SSE transport（非 stdio）
- go.work monorepo 管理 pkg/mcputil + servers/kali + servers/asset 三个 module
- 内置 /health 端点 + 请求日志中间件 + panic recovery + SIGTERM 优雅关闭

## 关键约束
- 模型路由：cc-switch → DeepSeek V4 Pro（不直连 OpenAI）
- 数据主权：自部署，不使用外部第三方服务
- 环境隔离：渗透工具完全容器化
- 凭据安全：敏感信息通过 Asset MCP 独立访问
- 所有代码注释、jsonschema、Tool Description、错误消息均为英文

├── data/                      # 持久化数据 + 配置
